# JoyStick Benchmark

Ferramenta gratuita da TEKSYS Eletronica para testar joysticks e gamepads (XInput e DirectInput): medicao de polling, latencia e jitter.

## Download

Baixe o instalador na pagina de Releases: https://github.com/Gilteksys/JoyStickBenchmark/releases/latest

## Requisitos

- Windows 10/11 64-bit
- Nao precisa ter o .NET instalado (aplicativo autocontido)

## Aviso (SmartScreen)

Por ser um app gratuito sem assinatura digital paga, o Windows pode mostrar "Windows protegeu o seu PC". Clique em "Mais informacoes" e depois "Executar assim mesmo".
